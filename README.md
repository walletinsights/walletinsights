### WalletInsights

Independent ratings of cryptocurrency hardware wallets — [walletinsights.io](https://walletinsights.io)

- **Open formula.** Every wallet is scored out of 100 from verified specifications: security 30%, recovery 20%, usability 20%, ecosystem 15%, privacy 15%. [Methodology](https://walletinsights.io/en/methodology/)
- **Open data.** Ratings, specifications and the security incident tracker under CC BY 4.0: [hardware-wallet-ratings](https://github.com/walletinsights/hardware-wallet-ratings) · [Zenodo](https://doi.org/10.5281/zenodo.24104206)
- **Security incidents.** Dated record of hardware wallet vulnerabilities, supply-chain attacks and fixes: [tracker](https://walletinsights.io/en/security-incidents/)

Found an error in the data? Open an issue in [hardware-wallet-ratings](https://github.com/walletinsights/hardware-wallet-ratings/issues) with a public source.

Contact: contact@walletinsights.io · Security reports: security@walletinsights.io
